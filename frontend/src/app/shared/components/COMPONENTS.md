# frontend/src/app/shared/components

## Responsabilidad

Agrupa componentes UI reutilizables en toda la aplicación.

## Archivos y función

- `navbar/`: barra superior con acciones de sesión y navegación.
- `sidebar/`: panel lateral de navegación.

## Relación con el resto del proyecto

Estos componentes son usados por el layout principal y por las pantallas autenticadas para mantener una navegación consistente.
